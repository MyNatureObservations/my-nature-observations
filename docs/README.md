# Documentation provenance

This public repository begins with a new, parentless commit from the reviewed
MNO v0.1 source snapshot. The prior development repository remains private and
is not part of this Git history.

Historical design decisions, specifications, test results and implementation
reports are retained as technical background. Old issue/PR numbers, commit IDs,
Actions links and status statements belong to that archive unless explicitly
identified otherwise. They are not references to public repository history.
Public readers do not need archive access to build or use MNO.

For current installation and feature information, use the [README](../README.md).
For building and environments, use the
[development/production guide](development/MNO_Development_Production_Environments.md).
The [release inventory](development/MNO_v0.1_Release_Readiness_Inventory.md)
records accepted scope and remaining publication decisions; its old SHA values
are provenance, not ancestors of this repository.

Future work to recreate separately: themes, Windows/Linux validation,
Restore/Import navigation to home, and the ongoing UX observations backlog.
No public issue numbers have been assigned yet. Historical links have not been
redirected to unrelated new issues. The old archive must remain private.
