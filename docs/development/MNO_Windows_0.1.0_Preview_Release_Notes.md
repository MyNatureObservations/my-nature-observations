# My Nature Observations 0.1.0 — Windows Preview

This is the first Windows 11 x64 preview of My Nature Observations, a
local-first nature journal. Create and revisit journal entries, add
photographs, and keep your journal on your computer. **Backup**, **Export**,
and **Restore** are available in Settings.

**Installer** · `My-Nature-Observations-0.1.0-windows-x64-rc1-7ae3313-setup.exe`

**SHA-256** · `FFA81CB8AF9A83E66DA5924A65BC739987AD33033885444FB94B4952A2CD6856`

Check the SHA-256 before opening Setup. The installer is unsigned.
Windows SmartScreen may display a protection warning, and Windows or
organization policy may block installation. If the checksum differs
or policy blocks Setup, stop. Setup may need an internet connection to
install Microsoft Edge WebView2 if the runtime is missing.
[Windows installation instructions](https://github.com/MyNatureObservations/my-nature-observations/blob/e7d219f36317039c9750b1cd4022357e6634420d/docs/MNO_Windows_Installation.md)

- Keep a backup outside the app installation and AppData folders before
  reinstalling or uninstalling. Leave the optional app-data deletion box
  unchecked to retain your journal and previous generations.
- Open Import of portable exports is unavailable on Windows. Use Restore
  for MNO backups. Distinct-version upgrades have yet to be verified.
- Preview support is scoped to Windows 11 x64.

Report reproducible problems through [GitHub Issues](https://github.com/MyNatureObservations/my-nature-observations/issues)
and ask questions in [GitHub Discussions](https://github.com/MyNatureObservations/my-nature-observations/discussions).
Keep private journal files and backups out of reports.
