# My Nature Observations 0.1.1 for macOS

This preview update is for Apple Silicon Macs running macOS 13 or later.

- **All entries** opens the journal reading view from both the new-entry and saved-entry pages.
- A heading at the start of an entry no longer adds extra space above it in the editor or reading view.
- After a restored journal is verified and opened, MNO returns to Home and confirms the restore. **Continue** opens the restored journal.
- Use the entry options menu in the reading view or on a saved entry to edit or permanently delete that entry. MNO asks for confirmation and keeps original photo files.

Keep an external journal backup before upgrading.
